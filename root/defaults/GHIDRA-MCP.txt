2. File → Configure → Developer → enable GhidraMCPPlugin.
3. Restart Ghidra if it asks.
4. Open a project. Keep it under /data.
5. Double-click a program so CodeBrowser opens. Plugin HTTP starts then.
6. The Bridge is already running.
